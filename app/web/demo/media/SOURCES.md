# Demo media sources

COCO 2017 validation images (https://cocodataset.org, Lin et al., 2014). Each photo is redistributed under
its own Flickr license as recorded in `instances_val2017.json`; only license ids 4, 5, 7 and 8 were eligible.
The files are the original bytes (no resizing, no edits). Author names and photo pages were looked up on
Flickr on 2026-10-07.
