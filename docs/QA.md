## 4. 남은 위험 · 미검증

- Qwen3-8B (2026-11-11): 같은 크기 이득이 작다 (원본에서 벌어진 정도 3.15비트 −16%, 4.16비트 −12%; DEMO §3 목표 40%). 표가 방법 5가지뿐이라 Auto-tune 이 고를 것은 GPTQ 비트 섞기와 INT8 뿐이다. 답변 차이는 20% · 26% 에서 작고, 16% 에서는 두 셋업 모두 무너진다. PPL 은 보정 seed 42 한 번만 쟀다 (seed 간 변동 미측정). 8B 의 GPU 평가 경로(`--live`)는 없다.
- 시연 셋업 (2026-11-13): 8B 화면은 기존이 무너지고 우리가 남는 크기(18% · 19%)만 고를 수 있다 — 측정 뒤 고른 시연용 선택이고, 같은 비트끼리의 작은 차이(20% · 26%)와 우리도 무너지는 크기(16% · 17%)는 화면에서 빠졌다 (데이터 · 문서에는 있음). 기존 방법은 GPTQ 같은 스칼라 양자화이고, 2비트 전용 벡터 양자화(QuIP# · AQLM)는 재지 않았다. 답의 "무너짐 · 읽힘" 은 사람이 읽은 판정이다. 0.6B 는 규칙을 만족하는 답변 크기가 없었다.
- 여러 벤치마크 (2026-11-12): 문항 상한(앞 1,000, MMLU 0-shot 분야마다 20)이라 전체 세트 점수가 아니고 논문 수치와 직접 비교하지 않는다. 보정 seed 42 하나. 기존 방법 칸은 과제마다 결과를 보고 고른 최선이라 기존 쪽에 유리하고, 판정은 다중 비교 보정이 없다. 큰 차이(8B 19% +33.0, 17% +19.1, 0.6B 19% +6.3 · 22% +4.7)는 모두 한 방법의 계단 사이 크기이고 기존 방법이 더 작은 크기다 — 같은 비트끼리면 20% · 26% 의 작은 차이(8B +1.4 · +0.2, 0.6B +0.7 · +0.5)가 맞는 비교다. 0.6B 는 같은 크기에서 과제 하나씩 기존이 낫다 (20% MMLU −3.2, 26% HellaSwag −2.9). 17% 의 8B 답은 다섯 중 넷이 반복으로 무너진다.
- YOLO11n: 26% 크기 Auto-tune 도 원본 대비 mAP −15.0. 가중치만 양자화 (활성값 FP32), CPU 측정, 3비트 크기는 배낭 해가 INT3 균일과 같아 화면에서 뺐다.

- 데모 세션(`runs/20261104_demo/s3150`)은 3라운드 · 측정 8건까지 끝났다 ([증거 §2.6](./evidence/2026-11-04_lowbit_track_m.md)). AI 최선 둘의 test PPL 은 출발점과 같은 트리 · GPU 로 쟀다 (26.82 · 26.51 vs 27.04). 보정 seed 42–46 로도 쟀다: 5/5 seed 에서 AI 가 낮고 평균 −3.48%, 부호 뒤집기 p = 1/32 ([증거 §2.7](./evidence/2026-11-04_lowbit_track_m.md)). turin(PCIe) 의 seed 42 값이 geneva(SXM4) 와 float 단위로 같다. 라운드 4 (배낭 재배정, LLM 없음) 는 검증 KL 0.39309 로 채택되지 않았고 ([§2.8](./evidence/2026-11-04_lowbit_track_m.md)), AI 옵션을 다른 예산의 배낭 해 5개에 옮긴 측정은 [§2.9](./evidence/2026-11-04_lowbit_track_m.md) 에 있다 (대조군 KL 이 세션 기록과 비트 단위로 같음).
