측정 기록 원장(ledger)을 근거로 읽고 결정적 검사(크기 예산 · 인용한 레코드 id 실존 · 수치가 인용 레코드로 지지됨)를 통과해야 하는 LLM 에이전트가 Linear 단위의 이질적 방법 × 형식 × 옵션 공간에서 배정을 제안하고, 같은 전체 모델 측정 수에서 가산 표 + 정확 배낭과 블랙박스 탐색보다 낮은 KL 의 레시피를 찾는다.

  • C1원장 검색 + 결정적 타입 검사 + LLM 의 층별 혼합 방법 배정 제안이, 같은 측정 수에서 해석적(배낭) · 블랙박스(랜덤 · 진화 · BO) 탐색보다 낫다
  • C2층 하나만 양자화한 end-to-end KL 표(patch floor 차감) + 저장 비트 예산 아래 정확 MCKP 가 좋은 시작점을 준다
  • C3GPTQ · AWQ · SmoothQuant · 회전 · NVFP4/MX/INT8/BFP · NF4/HQQ/RaZeR · N:M · KV 를 한 층별 공간에서 고른다

개선 기회

  • 층별 이질 공간에서 해석적 · 블랙박스와의 등측정 비교

    LLM 에이전트 압축 문헌에는 Linear 단위 방법 × 형식 × 옵션 배정을 가산 배낭 · 진화 · BO 와 같은 측정 수로 비교한 tier-1 사례가 없다. Hill 의 N=300 프로토콜과 ModelOpt · EvoPress 를 기준선으로 쓰면 이 자리를 실험으로 채울 수 있다.

  • 같은 실행 안의 측정 원장을 id 로 인용하게 하는 결정적 검사

    에이전트의 근거 없는 주장(~20%) · 조작(~80%) 문제가 보고됐고, 검색은 과제 간 경험에 머문다. 최적화 루프 안에서 인용 id 실존 · 수치 지지를 결정적으로 거르는 장치는 찾지 못했다. 다만 explorerreviewer 본문은 unknown 이다.

결론

C2(단일 층 KL 표 + 가산 + 정확 할당)는 핵심이 선점됐다(ZeroQ 2020, HIGGS, ModelOpt kl_div, Hill). 논문 기여가 아니라 강한 기준선으로 다뤄야 한다. C3(이질적 층별 공간)는 부분 선점이다(CALM 의 방법 3개 혼합, ModelOpt 의 포맷 + AWQ/SQ). 공간의 폭(회전 · NF4/HQQ/RaZeR · N:M · KV · 방법 옵션)과 Linear 단위만 남는다. H1("방법 혼합 > 비트 혼합")은 CALM Tab 4 가 이미 보였으므로 주장에서 내린다. 신규성은 C1 에 있다: 측정 원장 인용 + 결정적 수치 검사를 받는 LLM 이 층별 이질 공간에서, 같은 측정 수로 Hill 식 배낭 · ModelOpt · EvoPress · AMQ · TPE · LLM-seeded BO 보다 낫다는 것. 이를 선점한 문헌은 찾지 못했다. 가장 큰 위험은 동시기 ICLR'27 제출물 두 편 (AutoQS, Explorer–Reviewer)이고 본문 미확인이다. 그다음 위험은 실험 결과 자체다: LLM 우위는 예산에 따라 뒤집힐 수 있고(zhang-arxiv23), 직접 프롬프팅은 층별 할당이 불안정하다는 보고(TAP)가 있다.
